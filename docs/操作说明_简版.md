# Home Orchestrator v2｜简明操作说明

本地、确定性合成原型；未接真实Alexa或设备，无运行时LLM。以下为候选的预期用法，不代表完整验收通过。

1. **解压**：Windows 11 x64普通用户使用完整`HO_V2_Windows_x64.zip`附件（待发布），全部解压到可写本地目录，避开网盘/网络目录。“Code→Download ZIP”是仓库源码，不是自足便携包。
2. **打开**：双击`START_DEMO.cmd`，保留窗口，无需另装Python、PowerShell 7或Codex。浏览器未开时，用窗口当前所示本地地址，端口可能变化。
3. **解锁后Start**：用本次窗口的预览码点击Unlock，码不公开。解锁不会启动；选场景后明确点击Start synthetic preview。默认预期A→B→新的A，共三次虚拟效果，无需逐次批准。
4. **切场景**：Stop current demo停止事件源并保留效果；结束/停止后，Choose a new scene建立新世界，用同次启动的同一码解锁，再明确Start。网页业务安全HOLD是场景状态，不等于启动故障，不可绕过。
5. **关闭**：Stop app关闭整个服务；也可在启动窗口输入`STOP`，一次Enter，无需空回车或二次确认。等待App closed normally。默认30分钟从应用启动起算，切场不延长；自然到期另报。
6. **再启动**：正常关闭后再双击，新run使用新码；运行中不主动多开。

排障：浏览器未开，用窗口地址；文件损坏，重新完整解压；启动窗口提示旧实例退出未确认，或本次无法正常关闭时，保留现场/诊断并求助，不强退、不删锁、不绕过保护。
